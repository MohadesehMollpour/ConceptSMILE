# Security policy

Do not open a public issue for credentials, private medical data, unsafe model artefacts, or another security-sensitive disclosure.

Report the issue privately to `m.mollapour-papkyadeh-2023@hull.ac.uk` with the affected file/version, impact, and minimal reproduction information. Do not attach retinal datasets, access tokens, or patient metadata.

The repository is research software and is not approved for clinical deployment.
